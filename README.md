# Bilds Russia RP — Ultimate Edition

A cinematic responsive landing website for Bilds Russia RP.

## Run
Open `index.html` in a browser, or use any static hosting service.

## Customize
- Replace `https://discord.gg/YOURINVITE` in `index.html` with your Discord invite.
- Replace placeholder gallery/background assets with your own server artwork.
- Edit news/events/rules directly in `index.html`.
- The player count is a visual demo. Connect `script.js` to your real server API for live data.

## Structure
- index.html — full website
- style.css — responsive cinematic styling
- script.js — loader, animations, countdown and demo status
- assets/logo.svg — placeholder BR logo

No external backend is included, so there are no fake login/admin systems or exposed secrets.
